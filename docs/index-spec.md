# HHRating 指数评分标准（v1.0）

本文档是 HHRating 指数的唯一权威规范。任何代码实现必须与本文档一致，
并以 `tests/test_scoring.py` 中的用例锁定行为。规则修订须同步更新本文档并提升版本号。

## 1. 指数总则

- 指数为 **5 位字符串**，如 `86752`，自左至右依次为：
  1. **综合得分**（Overall）
  2. **名人推荐值**（Celebrity）
  3. **人气度**（Popularity）
  4. **网上得分**（Online Rating）
  5. **出现时间**（Age / Heritage）
- 每位取值整数 `1–9`，**由差到好**；`1` 最差，`9` 最好。
- 任一维度数据缺失时该位记 `0`，表示"暂无数据"，综合得分按可得维度权重归一化计算；
  若四个输入维度全部缺失，综合得分记 `0`。
- 所有原始指标必须附带 `data_date`（数据快照日期）与来源，见 `docs/data-dictionary.md`。

## 2. 第 4 位：网上得分（Online Rating）

输入：跨点评平台归一化后的平均评分 `online_rating`（0–5 分制，
大众点评/美团 5 分制直接采用，10 分制平台须折算为 5 分制后加权）。

| online_rating 区间 | 分值 |
|--------------------|------|
| [4.80, 5.00] | 9 |
| [4.60, 4.80) | 8 |
| [4.40, 4.60) | 7 |
| [4.20, 4.40) | 6 |
| [4.00, 4.20) | 5 |
| [3.70, 4.00) | 4 |
| [3.40, 3.70) | 3 |
| [3.00, 3.40) | 2 |
| [0.00, 3.00) | 1 |
| 缺失 | 0 |

区间为**左闭右开**（最高档为闭区间）。

## 3. 第 3 位：人气度（Popularity）

输入：全网点评总数 `review_count`（各平台点评/评价条数之和）与
社交媒体热度 `social_mentions`（小红书笔记、微博话题阅读/讨论等可统计条目数，可选）。

### 3.1 基础分（按 review_count 分桶，左开右闭）

| review_count | 分值 |
|--------------------|------|
| < 500 | 1 |
| [500, 2 000) | 2 |
| [2 000, 5 000) | 3 |
| [5 000, 10 000) | 4 |
| [10 000, 30 000) | 5 |
| [30 000, 60 000) | 6 |
| [60 000, 100 000) | 7 |
| [100 000, 300 000) | 8 |
| ≥ 300 000 | 9 |

### 3.2 社媒修正

- `social_mentions ≥ 1 000 000`：基础分 +2
- `social_mentions ≥ 100 000`：基础分 +1
- 修正后封顶 9，下限 1。

缺失 `review_count` 时该位记 0（社媒数据不足以独立支撑人气判断）。

## 4. 第 2 位：名人推荐值（Celebrity）

采用**加分点数制**，先按下表累计 `points`，再映射为分值。

### 4.1 加分表

| 信号 | 点数 |
|------|------|
| 米其林三星（任一年份入选） | +8 |
| 米其林二星 | +6 |
| 米其林一星 | +4 |
| 米其林必比登推介（Bib Gourmand） | +2 |
| 米其林餐盘奖（Plate） | +1 |
| 黑珍珠三钻 | +6 |
| 黑珍珠二钻 | +4 |
| 黑珍珠一钻 | +2 |
| 国家级/省部级烹饪大师主理或坐镇 | +2 |
| 名人（公众人物）实名推荐，每人 | +1（上限 +3） |
| 全国性权威媒体报道（《舌尖上的中国》、央视、人民日报等），每次 | +1（上限 +2） |

同一奖项只计一次（取历史最高级别）；奖项点数取所有获奖记录中的**最高档**（不叠加）。

### 4.2 点数 → 分值映射

`分值 = min(9, points + 1)`；`points = 0` 时分值为 1。
无任何名人/奖项信号时记 1（而非 0）：0 仅用于"字段缺失"。

## 5. 第 5 位：出现时间（Age / Heritage）

输入：店铺创立年份 `founded_year`。以数据快照年份计年龄 `age = data_year − founded_year`。

| 年龄（年） | 分值 |
|------------|------|
| < 5 | 1 |
| [5, 10) | 2 |
| [10, 20) | 3 |
| [20, 35) | 4 |
| [35, 50) | 5 |
| [50, 70) | 6 |
| [70, 90) | 7 |
| [90, 120) | 8 |
| ≥ 120 | 9 |
| 缺失 | 0 |

`founded_year` 晚于快照年份视为数据错误，按 1 分处理并记录告警。

## 6. 第 1 位：综合得分（Overall）

对四个非综合维度按下列权重加权（权重和为 1）：

| 维度 | 权重 |
|------|------|
| 网上得分 | 0.35 |
| 人气度 | 0.25 |
| 名人推荐值 | 0.20 |
| 出现时间 | 0.20 |

- 计算式：`overall = round(Σ digitᵢ × wᵢ)`（四舍五入，.5 进位），结果限制在 [1, 9]。
- 某维度缺失（记 0）时，剔除该维度并将其权重按剩余维度**归一化**后再加权。
- 全部缺失时综合得分记 0。

## 7. 发布规则

- 指数一经发布即不可变（immutable release）；数据更新后重新计算，发布产物含生成时间戳。
- 发布产物：`published/hhrating-index.json`（机器可读，含逐位明细）、
  `published/index.md`（榜单表）、`published/index.html`（可排序静态页）。
- JSON 顶层含 `schema_version`、`generated_at`、`spec_version`（本规范版本）。
